## 🇺🇿 Qaraqalpaqsha

### 🎯 Joba haqqında

**Qaraqalpaq urıwları** — qaraqalpaq xalqınıń urıwlıq shejiresin sanlaw formatında saqlaǵan veb-joba. 50+ urıw, 300+ tiyre/kóshe haqqında tólıq maǵlıwmat qamaydı.

**Tiykarǵı maqsetlar:**
- 📚 Qaraqalpaq urıwlıq qurılımın saqlap qalıw
- 🔍 Urıwlıq tegdi tez anıqlaw
- ⚖️ Ekzogamiya erejelerin tekseriw
- 🎓 Ǵılımiy-izertlew jumıslarına qollap-quwatlaw

### ✨ Imkániyatlar

| Imkániyat | Sıpatlaması |
|-----------|-------------|
| 🌳 **Interaktiv sxema** | D3.js tiykarındaǵı svoralanatın urıwlıq teregi |
| 📋 **Tizimlik kórinis** | Ierarxiyalıq tizim, bejalar menen |
| 📊 **Statistika** | Diagrammalar, KPI kartalar, top-10 urıwlar |
| 💑 **Ekzogamiya tekseriw** | Neke ruqsatlılıǵın avtomat tekseriw |
| 🔍 **Aqıllı izlew** | Urıw atı boyınsha tez izlew, ata-babaların kóretiw |
| 🌙 **Tema** | Qaranǵı / Aqshıl tema almaslastırıw |
| ⭐ **Tańdaǵanlar** | Tez kirisiw ushın urıwlardı saqlap qoyıw |
| 🔗 **Bólisiw** | Urıw betine silteme kópirisiw |
| 🖨️ **Basıp shıǵarıw** | Tizimdi PDF qılıp alıw |
| 🔄 **Ush til** | Qaraqalpaqsha · Qazaqsha · Orıssha |

## 🇷🇺 Русский

### 🎯 О проекте

**Qaraqalpaq urıwları** — веб-проект для сохранения родословной каракалпакского народа в цифровом формате. Содержит данные о 50+ родах, 300+ тийре/коше.

**Основные цели:**
- 📚 Сохранение каракалпакской родовой структуры
- 🔍 Быстрое определение родового происхождения
- ⚖️ Проверка правил экзогамии
- 🎓 Поддержка научно-исследовательской работы

### ✨ Возможности

| Возможность | Описание |
|-------------|----------|
| 🌳 **Интерактивная схема** | Сворачиваемое родовое дерево на D3.js |
| 📋 **Списковое представление** | Иерархический список с бейджами |
| 📊 **Статистика** | Диаграммы, KPI карточки, топ-10 родов |
| 💑 **Проверка экзогамии** | Автоматическая проверка разрешения брака |
| 🔍 **Умный поиск** | Быстрый поиск с показом пути предков |
| 🌙 **Тема** | Переключение тёмной / светлой темы |
| ⭐ **Избранное** | Сохранение родов для быстрого доступа |
| 🔗 **Поделиться** | Копирование ссылки на конкретный род |
| 🖨️ **Печать** | Экспорт списка в PDF |
| 🔄 **Три языка** | Каракалпакский · Казахский · Русский |

### 🚀 Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/uz-itlife/qaraqalpaq-ruwlari.git
cd qaraqalpaq-ruwlari

# Запустить локальный сервер
python -m http.server 8080
# Открыть: http://localhost:8080
```

**Требования:** современный браузер с включённым JavaScript.
